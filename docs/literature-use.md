## 知识库入口与使用顺序

共享知识库根目录为 `/mnt/d/works/papers`，从本项目只读访问。以下链接按本项目与 `papers/` 为同级目录组织。

1. 从 [topic-index.md](../../papers/topic-index.md) 定位主题，并从 [review-index.md](../../papers/review-index.md) 查询已有审核意见。
2. 优先读取与当前问题相关的主题页：
   - [数字脉冲处理与堆积恢复](../../papers/methods/数字脉冲处理与堆积恢复.md)
   - [脉冲形状甄别与粒子鉴别](../../papers/methods/脉冲形状甄别与粒子鉴别.md)
   - [闪烁体的光产额与能量分辨率](../../papers/concepts/闪烁体的光产额与能量分辨率.md)
3. 沿主题页链接读取相关 `sources/` 精读笔记；已有记录足以回答的问题直接复用。
4. 关键公式、参数或引用证据有缺口时，按具体问题定点回查原文，保留 DOI、页码、公式、图表等定位信息。

## 采用记录

2026-09-30：建立共享库使用约定，已确认上述五个入口文件存在。本次尚未登记新的文献采用结论；入口检查不代表完成文献审核或算法验证。

以后每条实际采用记录使用以下字段，来源路径以共享库根目录为基准，项目验证路径以项目根目录为基准。

| 字段 | 记录要求 |
| --- | --- |
| 日期与研究问题 | 记录读取日期、本项目当前要解决的问题。 |
| 文献结论 | 写明原文或精读笔记支持的结论及其限制，区分实验结果、模拟结果和作者提出的方案。 |
| 本项目采用方式 | 写明采用的公式、参数、方法或评价标准，以及本项目额外引入的假设或调整。 |
| 来源位置 | 记录主题页及章节、`sources/` 笔记及章节；需要时补充原文文件、DOI／链接、页码、公式或图表编号。 |
| 探测器与信号条件 | 保留晶体／探测器、读出与整形方式、粒子种类、能量范围及能量定义。 |
| 采样与噪声条件 | 保留采样率／时间分箱、记录窗、量化、噪声模型及幅度；未给出的项目明确写“未给出”。 |
| 计数率与堆积条件 | 保留源注入率、探测事件率或反应率的定义，以及时间分布、堆积程度和适用范围。 |
| 验证条件与性能定义 | 写明数据来自实验或模拟、样本规模、指标定义，以及是否已知脉冲数、类型、到达时间等真值。 |
| 原有人工审核状态 | 按来源原样保留状态、审核意见位置及读取日期；未标注时记“未标注”，不因项目复用而升级审核状态。 |
| 项目验证与待验证事项 | 区分已完成的项目计算与尚待验证的迁移假设，链接相关 Notebook、代码和结果。 |

性能比较须同时保留上述条件。其他探测器上的恢复效率、能量分辨率或可处理计数率，不能直接作为本项目 GAGG 模型的性能结果。
