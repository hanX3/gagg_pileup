# 固定候选下的 α/γ 网络电荷与类别先验消融

研究问题：上一轮混合方法改善α、削弱γ，两个显式网络惩罚项分别起了什么作用？本轮仅复用20个已公开开发窗口，完整过程追加到本地[ML Notebook第9节](../../../jupyter/codex_0006_Alpha_Gamma_Pileup_ML_Literature_20261016.ipynb#alpha-gamma-prior-ablation-20261019)。这是开发诊断，没有新的独立最终测试。

## 输入与控制

沿用两种γ（轫致辐射、661.657 keV）、α源1/10 MHz、γ源10 MHz，各条件5窗；每窗20 μs，原生共享SiPM微胞响应，2 ns完整含噪电压，中央[5,15) μs评价。源注入率不是探测率。阈上真值791个α、86个γ；电荷Q为实现p.e.，没有换算为沉积能量。

只读取上一轮保存的U-Net输出、盲拟合输出与独立标定。密集输出重新经过不依赖Torch的相同解码器，与20份已保存事件列表逐项核对。网络权重、波形、标定和缓存哈希均核对；没有重新训练或生成G4数据。

四组共用盲候选并集、初始类型与电荷、固定到达时刻、用于模板的初始Q，以及由原盲拟合产生的固定噪声权重。候选最小间隔4 ns、内部候选Q≥40 p.e.，保留同样的全部候选。优化仅改变非负电荷与离散类型；无到时搜索或残差补峰。相邻100 ns内比较四种类型组合，每轮进行全局非负电荷重估，至多6轮。

目标为固定加权波形残差平方和，加两个显式惩罚：电荷项中心为已解码的单个网络Q，尺度为`0.35*max(500,Q_NN)`；类别项为`-2*λC*log(s_k/(s_alpha+s_gamma))`，分数下限1e-4。网络分数尚未概率校准。非神经候选仅在8 ns内有网络事件时赋先验，索引沿用原实现的`round(t_NN/2 ns)`。Q中心在两个类别假设间共用，正是本轮要检查的耦合。

`none/charge/class/both`的(λQ,λC)分别为(0,0)/(10,0)/(0,10)/(10,10)，强度10沿用上一轮，不在本轮重新选参。“无显式先验”组仍包含共同的网络候选、初值和模板Q。该诊断与原生产混合流程的时间搜索、增峰不同，不可混称完整算法改进。

评价沿用Q≥500 p.e.、类型无关一对一时间匹配≤10 ns、类型正确且|ΔQ/Q|≤20%；报告阈值也为估计Q≥500 p.e.。另在报告筛选前固定共同候选的时间配对，区分无候选、低于报告门槛、错类型、电荷失败及完整恢复，真值仅在全部盲拟合结束后打开。

## 实际结果

| 显式先验 | α完整恢复 | γ完整恢复 | α完整precision | γ完整precision | 额外预测 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无 | 483/791（61.1%） | 42/86（48.8%） | 69.8% | 37.2% | 53 |
| 仅电荷 | 517/791（65.4%） | 37/86（43.0%） | 67.1% | 51.4% | 83 |
| 仅类别 | 503/791（63.6%） | 42/86（48.8%） | 68.1% | 54.5% | 59 |
| 两者 | 520/791（65.7%） | 38/86（44.2%） | 67.4% | 53.5% | 83 |

本轮不支持把γ退步简单归因于“类别分数未校准”。仅电荷项相对无显式先验，α+34、γ−5；γ差为−5.81个百分点，按四源条件分层的2000次成对整窗重采样区间为−10.34至−2.15个百分点。仅类别项α+20、γ净变化0，γ区间−4.71至+5.95个百分点；该组实际上损失4个原成功γ、补回另外4个，不能称为对每个γ均无害。

共同时间配对下，仅电荷组使6个原成功γ失败，另补回1个；6个损失中5个转为α、1个电荷超差。全部γ的错类型由33变40，弱γ500–1000 p.e.恢复24/53→20/53。强前史≥200 mV的γ恢复3/18→2/18，<50 ns近邻γ为11/44→8/44；这些分层重叠，不当作独立因果效应。仅类别组的额外预测也由53增到59，α完整precision略降，仍有取舍。

事后按时间戳/真值索引取首个“无先验成功、仅电荷错分”的γ作为解释图：真值554.14 p.e.，网络Q为967.02 p.e.；无先验拟合为584.67 p.e.的γ，仅电荷拟合为948.95 p.e.的α。两个类别共用同一Q惩罚可把分型与电荷分配耦合。此例只作失败解释，整窗多个候选的惩罚同时改变，不能据此把所有失败归因于单事件或证明物理不可分。

原完整盲拟合与原完整混合结果作为同一20窗的背景参照单独列在summary：旧拟合α471/791、γ38/86，旧混合强度10为520/791、38/86。参照流程的候选、浮动时刻及增峰不同，不与四组构成单因素因果比较。
