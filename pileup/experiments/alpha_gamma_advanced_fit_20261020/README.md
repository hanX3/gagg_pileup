# Independent native comparison of short-prefix conditional fits

2026-10-20. This campaign keeps the existing GAGG/SiPM physics and complete analog voltage. It compares seven isolated-pulse charge/type estimators: original-calibration GLS, expanded-calibration GLS, self-consistent Gaussian fitting, rank-8/rank-16 covariance models, and two combinations with finite calibration-mean uncertainty. At most one pulse is assumed; this is not a blind pileup or free-lifetime benchmark.

The native plan contains 420 independent ROOT events: 168 calibration, 84 development, and 168 test. The first four validation events are part of calibration. New events use source alpha energies 1.5/2.5/5.486/8 MeV or monoenergetic gamma 0.1/0.2/0.661657/1.5 MeV, at three saved positions. One primary is emitted at 5 us in a 20 us event. Zero-signal gamma events are retained. The `rate_hz=0` field is unused in this single-primary mode. Source energy, deposited energy and realized avalanche charge are separate quantities.

The new data are added to the original 149 calibration and 45 development events. The old public 174-event test is excluded from model selection and new-test scoring. Inference code, calibration and development-only method/window selection are frozen before any new test event. The predeclared primary short goal is 150 ns after the observed trigger, with 20 ns pre-trigger; all 100/150/200/300/500 ns results are retained. Charge success requires error within 5%; type and joint charge/type success are also reported for each particle separately, including missed targets in the denominator.

`source/`, `bin/`, `macros/`, `logs/`, the manifest, environment, Git state and working patch preserve actual production inputs. `inference-source/` preserves the final inference implementation; it is created at the development freeze. ROOT files stay under `g4/data/`. Native processes are serial internally, with at most eight independent jobs and starts at least one second apart. The data and numerical artifacts are local under `jupyter/artifacts/alpha_gamma_advanced_fit_20261020/`; the protocol is saved before production. No ADC clipping rejection is applied.

Run from the project root with the project Python environment:

```bash
bash tools/run_gagg_python.sh pileup/experiments/alpha_gamma_advanced_fit_20261020/analyze_frozen.py test --output jupyter/artifacts/alpha_gamma_advanced_fit_20261020 --workers 4
bash tools/run_gagg_python.sh pileup/experiments/alpha_gamma_advanced_fit_20261020/analyze_frozen.py summarize --output jupyter/artifacts/alpha_gamma_advanced_fit_20261020
```

These commands verify/reuse complete saved results. For a clean numerical replay, use a copied artifact folder containing the same calibration, input records, freeze and native inputs, and an empty `test/` folder; original results remain intact. The frozen scripts use saved source files rather than switching Git commits. Dependencies are recorded in the freeze and `requirements-analysis.lock.txt`.

To prepare or rerun one native event with exactly its saved seeds and physics, use `replay_native.py --label LABEL --prepare-only` or omit `--prepare-only` to execute. It always creates a new macro/run record and a fresh second-resolution ROOT filename. A same-seed replay is not an independent test. The saved C++ source can be built against an installed compatible Geant4/ROOT toolchain on another machine; the retained ELF binary belongs to the recorded Linux environment.

The final development choice was `expanded_gls`. On the new independent native test at 150 ns after trigger, joint charge-within-5% and correct-type success was alpha16/16、gamma11/15 for original calibration GLS, alpha16/16、gamma9/15 for expanded calibration GLS, and alpha16/16、gamma9/15 for the selected method. All seven methods and five windows remain in `test-summary.json`; `paired-comparisons.json` keeps paired ROOT bootstrap ranges. Local nominal 95% intervals are checked by observed coverage and are not certified stopping intervals. `report.json` includes optimizer/boundary failures, no-signal false triggers and the synthetic-double assumption controls.

Three development attempts waited in the VirtualBox shared-folder driver before event completion. Their original macros/logs and the one 314-byte ROOT header are retained in `interrupted_attempts`; same-seed retries completed using identical executable bytes and ordinary local temporary logs. These replace unfinished attempts and do not add independent observations. The final test runner `run_test_local.py` uses a regular local executable/log cache, with hashes and actual commands recorded; all ROOT destinations remain on the shared folder. No symbolic link is needed. The observed driver wait also occurred outside the sandbox, so it is not attributed solely to sandboxing.

All 420 ROOT files passed provenance/seed/configuration/charge-ancestry checks; 280 summary groups were independently rescored. Nine numerical-reference tests, four historical development endpoint regressions, four native future-NaN/time-shift/replay checks and two frozen-source replays passed. Exact records are under `jupyter/run_records/alpha_gamma_advanced_fit_20261020/`. The original short-window fitter and old numerical artifacts remain unchanged. Conclusions apply to isolated realized avalanche charge under the calibrated same-domain simulation, not free lifetimes, deposited-energy resolution or high-rate capability.
