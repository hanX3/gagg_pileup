# α＋γ 多任务网络与联合物理拟合

研究问题：从完整含噪电压恢复未知数量事件的类型、到达时间和实现电荷，检验 CNN、U-Net 及网络候选＋物理拟合是否改善已有扩展标定拟合，α、γ 同等重要。当前过程与最终表格在本地 [Notebook 第8节](../../../jupyter/codex_0006_Alpha_Gamma_Pileup_ML_Literature_20261016.ipynb#alpha-gamma-ml-implementation-20261016) 维护。

## 固定条件与划分

- 物理沿用 `alpha_gamma_context_calibration_20261016` 的 GAGG 与 S13360 原生共享微胞响应；两种 γ 为轫致辐射谱和 661.657 keV 单能源。没有更改光产额、衰减时间或器件参数。
- 每个 ROOT 一个 20 μs 窗，2 ns 采样，中央 [5,15) μs 评价。使用完整 `analog_mV`，假定采集动态范围足够。
- 52 个原生混合训练窗：40 个旧窗＋12 个新增 γ 源50 MHz窗；另141个已有孤立/受控前史窗参与训练。20 个已有混合验证窗用于选择。所有切片在按完整 ROOT/种子划分之后生成。
- 16 个上一轮混合窗口只作已公开回归；43 个已有原生孤立/前史窗作开发控制。以上均不称为新的未见最终测试。
- 新最终测试16窗：两种γ × α源1/10 MHz × 每条件4窗，γ源10 MHz。所有方法和超参数冻结后才生成；训练没有访问其真值。
- 评价Q≥500 p.e.、类型无关一对一时间匹配≤10 ns，完整恢复另要求类型正确和电荷误差≤20%。Q是实现电荷，不是沉积能量；源注入率不等于探测率。

## 实现

CNN使用扩张卷积（29,934参数），U-Net使用五级下采样（145,774参数）。八个固定电压特征保留尺度、导数、两类模板反卷积与局部前史。各类分别输出事件热图、logQ和时间偏移，不输入真实数量、类型、时刻或源率。4.096 μs切片，两侧各1.2 μs保护，中央1.696 μs监督/输出；最小输出间隔4 ns为表示容量限制。

两网络各1600步、batch=8，AdamW固定学习率0.001。训练85%混合/15%孤立前史，60%按α/γ平衡的事件中心切片、40%均匀切片。学习标签Q≥250 p.e.，报告Q≥500 p.e.。验证按两类×四条件等权完整恢复F1选检查点及独立α/γ阈值。

混合流程使用神经候选与盲拟合候选并集、联合时刻/电荷/类别搜索及残差增峰，类别不锁定；神经电荷/类别软先验强度仅在验证集从0/10/100中选择。保留纯网络与单独拟合作共同对照。

## 实际结果（2026-10-17完成）

16个冻结后新原生测试窗口，合计641个α和75个γ阈上目标。**没有达到α、γ逐事件恢复同时改善的目标，不替换现有拟合默认流程。**

| 方法 | α完整恢复 | γ完整恢复 | α完整precision | γ完整precision | 额外预测 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 扩展标定拟合 | 374/641（58.3%） | 35/75（46.7%） | 70.9% | 37.6% | 41 |
| 多任务CNN | 342/641（53.4%） | 25/75（33.3%） | 67.3% | 41.7% | 20 |
| 多任务U-Net | 375/641（58.5%） | 21/75（28.0%） | 69.3% | 51.2% | 27 |
| U-Net＋物理拟合 | 416/641（64.9%） | 28/75（37.3%） | 69.0% | 38.9% | 64 |

网络及阈值、混合强度均只由20窗开发验证选择。验证完整F1：拟合0.5687、CNN0.5355、U-Net0.5872；U-Net混合强度0/10/100为0.5847/0.5908/0.5643，选10。两网络均选1600步；在本机缓存完整训练约122/112秒，首次共享目录受阻时间不作为训练吞吐。

混合流程的α恢复增加42个（+6.55个百分点），γ减少7个（−9.33个百分点）。按源条件分层的成对窗口bootstrap95%区间分别为+2.62至+10.49、−16.88至−1.23个百分点；不包含模型/标定系统误差。漏检136→106，但额外预测41→64、误拆分标志0→10、误合并标志46→40。所有方法未知事件数/类别/时刻，未拒绝削顶窗口。

退步集中在弱γ：500–1000 p.e.组，拟合19/49完整恢复，U-Net8/49、混合10/49；混合错分型由15/49增至26/49。前史≥200 mV组，拟合2/13、两种U-Net流程均0/13；<50 ns近邻γ为10/38→3/38（U-Net）或5/38（混合）。分层互相重叠、只作事后诊断，不能证明物理不可分。高α源10 MHz条件合计γ为4/31（拟合）、2/31（CNN/U-Net）、4/31（混合），仍很差。

旧16窗回归也出现同样取舍：拟合α378/656、γ31/64，混合α418/656、γ25/64。43原生开发控制中拟合20/22 α、3/3 γ，混合21/22 α、3/3 γ，γ数量不足。49个人工控制的40个双脉冲中（80事件），拟合80/80、CNN46/80、U-Net45/80、混合71/80；这是匹配均值模板＋0.1 mV白噪声，不能推断真实时间分辨率。

新测试的条件Q偏差/宽度、误报、分型及不确定度见 [test-summary.json](../../../jupyter/artifacts/alpha_gamma_ml_20261016/test-summary.json) 和Notebook；Q误差同时按全部时间匹配及正确类型时间匹配报告，不只挑完整恢复成功事件。四幅示例按每条件首个预定窗口、首个阈上γ选择，与拟合成败无关。
